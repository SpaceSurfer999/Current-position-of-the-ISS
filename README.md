# Трекер МКС (ISS Tracker)
- Программа для отслеживания Международной космической станции (МКС) в реальном времени. Отображает текущее положение МКС на карте мира и список космонавтов на борту.

## 🚀 Возможности

- Показывает текущие координаты МКС
- Выводит список космонавтов на борту
- Обновляет данные
